# 📈 MarketScope — Share Market Forecasting

MarketScope is a web-based stock market analysis dashboard focused on Indian equities. It provides an interactive interface for exploring historical stock prices, visualizing market trends, and analyzing stocks using technical indicators.

### ✨ Features
- Interactive stock price charts
- Stock search and historical market data
- Technical indicators such as RSI and MACD
- Market overview and price movement analysis
- Responsive dashboard interface

### 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript, Plotly.js
- **Backend:** Python, FastAPI, Pandas, yfinance
- **Deployment:** GitHub Pages and Render
